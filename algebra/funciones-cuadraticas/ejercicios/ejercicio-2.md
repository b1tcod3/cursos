# Ejercicio 2: Vértice e interceptos de una parábola

Se lanza una roca hacia arriba desde la cima de un acantilado de 112 pies de altura sobre el océano, con una velocidad de 96 pies por segundo. La altura de la roca sobre el océano se modela con la ecuación:

$$H(t) = -16t^2 + 96t + 112$$

a. ¿Cuándo alcanza la roca su altura máxima?

b. ¿Cuál es la altura máxima de la roca?

c. ¿Cuándo cae la roca al océano?

<details>
<summary>Ver respuesta</summary>

**a.** El vértice:

$$h = -\frac{96}{2(-16)} = \frac{96}{32} = 3$$

La roca alcanza la altura máxima después de **3 segundos**.

**b.** La altura máxima:

$$k = H(3) = -16(3)^2 + 96(3) + 112 = -144 + 288 + 112 = 256$$

La altura máxima es de **256 pies**.

**c.** Resolvemos $H(t) = 0$:

$$t = \frac{-96 \pm \sqrt{96^2 - 4(-16)(112)}}{2(-16)} = \frac{-96 \pm \sqrt{16384}}{-32} = \frac{-96 \pm 128}{-32}$$

$$t = \frac{-96 + 128}{-32} = -1 \qquad \text{o} \qquad t = \frac{-96 - 128}{-32} = 7$$

La solución negativa queda fuera del dominio razonable. La roca cae al océano después de **7 segundos**.
