# Ejercicio 3: Inversa de una función racional

Encuentra la inversa de:

$$f(x) = \frac{x + 3}{x - 2}$$

<details>
<summary>Ver respuesta</summary>

Reemplazamos $f(x)$ por $y$ e intercambiamos:

$$y = \frac{x + 3}{x - 2}$$
$$x = \frac{y + 3}{y - 2}$$

Despejamos $y$:

$$x(y - 2) = y + 3$$
$$xy - 2x = y + 3$$
$$xy - y = 2x + 3$$
$$y(x - 1) = 2x + 3$$
$$y = \frac{2x + 3}{x - 1}$$

$$f^{-1}(x) = \frac{2x + 3}{x - 1}, \qquad x \neq 1$$
