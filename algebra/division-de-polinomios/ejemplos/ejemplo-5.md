# Ejemplo 5: División sintética de un polinomio de cuarto grado

Usa división sintética para dividir:

$$-9x^4 + 10x^3 + 7x^2 - 6 \quad \text{entre} \quad x - 1$$

## Solución

### Paso 1: Escribir $k$ y los coeficientes

El divisor es $x - 1$, así que $k = 1$. Nota que **no hay término en $x$**, así que usamos un cero como coeficiente. Coeficientes: $-9$, $10$, $7$, $0$, $-6$.

### Paso 2: Bajar y operar

| Operación | Resultado |
|-----------|-----------|
| Bajar | $-9$ |
| $-9 \cdot 1$ | $-9$ |
| $10 + (-9)$ | $1$ |
| $1 \cdot 1$ | $1$ |
| $7 + 1$ | $8$ |
| $8 \cdot 1$ | $8$ |
| $0 + 8$ | $8$ |
| $8 \cdot 1$ | $8$ |
| $-6 + 8$ | $2$ (resto) |

### Resultado

El cociente es $-9x^3 + x^2 + 8x + 8$ y el resto es $2$:

$$-9x^3 + x^2 + 8x + 8 + \frac{2}{x - 1}$$
