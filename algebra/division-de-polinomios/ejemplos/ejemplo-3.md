# Ejemplo 3: División sintética de un polinomio de segundo grado

Usa división sintética para dividir:

$$5x^2 - 3x - 36 \quad \text{entre} \quad x - 3$$

## Solución

### Paso 1: Escribir $k$ y los coeficientes

El divisor es $x - 3$, así que $k = 3$. Coeficientes del dividendo: $5$, $-3$, $-36$.

### Paso 2: Bajar y operar

Bajamos el coeficiente principal, multiplicamos por $k$ y sumamos columna a columna:

| Operación | Resultado |
|-----------|-----------|
| Bajar | $5$ |
| $5 \cdot 3$ | $15$ |
| $-3 + 15$ | $12$ |
| $12 \cdot 3$ | $36$ |
| $-36 + 36$ | $0$ (resto) |

### Resultado

El cociente es **$5x + 12$** y el resto es **$0$**. Así, $x - 3$ es factor del polinomio original.

### Verificación

$$(x - 3)(5x + 12) + 0 = 5x^2 + 12x - 15x - 36 = 5x^2 - 3x - 36 \quad ✔$$
