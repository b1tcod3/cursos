# Ejemplo 1: División larga de un polinomio de segundo grado

Divide:

$$5x^2 + 3x - 2 \quad \text{entre} \quad x + 1$$

## Solución

### Paso 1: Dividir el término principal del dividendo por el del divisor

$$\frac{5x^2}{x} = 5x$$

### Paso 2: Multiplicar y restar

$$5x(x + 1) = 5x^2 + 5x \qquad (5x^2 + 3x) - (5x^2 + 5x) = -2x$$

Bajamos el $-2$: $5x^2 + 3x - 2$ → nos queda $-2x - 2$.

### Paso 3: Repetir

$$\frac{-2x}{x} = -2 \qquad -2(x + 1) = -2x - 2 \qquad (-2x - 2) - (-2x - 2) = 0$$

### Resultado

El cociente es **$5x - 2$** y el resto es **$0$**:

$$\frac{5x^2 + 3x - 2}{x + 1} = 5x - 2$$

### Verificación

$$(x + 1)(5x - 2) = 5x^2 - 2x + 5x - 2 = 5x^2 + 3x - 2 \quad ✔$$

> El resto $0$ indica que el divisor es un **factor** del dividendo.
