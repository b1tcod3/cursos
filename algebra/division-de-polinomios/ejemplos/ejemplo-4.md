# Ejemplo 4: División sintética de un polinomio de tercer grado

Usa división sintética para dividir:

$$4x^3 + 10x^2 - 6x - 20 \quad \text{entre} \quad x + 2$$

## Solución

### Paso 1: Escribir $k$ y los coeficientes

El divisor es $x + 2$, así que $k = -2$. Coeficientes del dividendo: $4$, $10$, $-6$, $-20$.

### Paso 2: Bajar y operar

| Operación | Resultado |
|-----------|-----------|
| Bajar | $4$ |
| $4 \cdot (-2)$ | $-8$ |
| $10 + (-8)$ | $2$ |
| $2 \cdot (-2)$ | $-4$ |
| $-6 + (-4)$ | $-10$ |
| $-10 \cdot (-2)$ | $20$ |
| $-20 + 20$ | $0$ (resto) |

### Resultado

El cociente es **$4x^2 + 2x - 10$** y el resto es **$0$**. Así, $x + 2$ es factor de $4x^3 + 10x^2 - 6x - 20$.

> La gráfica de $f(x) = 4x^3 + 10x^2 - 6x - 20$ muestra un cero en $x = k = -2$, lo que confirma el resultado.
