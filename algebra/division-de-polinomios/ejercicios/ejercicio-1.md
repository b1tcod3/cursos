# Ejercicio 1: División larga

Divide:

$$16x^3 - 12x^2 + 20x - 3 \quad \text{entre} \quad 4x + 5$$

<details>
<summary>Ver respuesta</summary>

$$4x^2 - 8x + 15 - \frac{78}{4x + 5}$$

Es decir, cociente $4x^2 - 8x + 15$ y resto $-78$.

**Verificación:** $(4x + 5)(4x^2 - 8x + 15) - 78 = 16x^3 - 12x^2 + 20x - 3$.
</details>
