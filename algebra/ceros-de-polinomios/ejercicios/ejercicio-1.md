# Ejercicio 1: Ceros de una función polinómica

Encuentra los ceros de:

$$f(x) = 2x^3 + 5x^2 - 11x + 4$$

<details>
<summary>Ver respuesta</summary>

Posibles ceros racionales: factores de $4$ entre factores de $2$: $\pm 1, \pm 2, \pm 4, \pm \frac{1}{2}$.

Con división sintética, $x = 1$ da resto 0:

$$2x^3 + 5x^2 - 11x + 4 = (x - 1)(2x^2 + 7x - 4) = (x - 1)(2x - 1)(x + 4)$$

Los ceros son:

$$x = 1, \quad x = \frac{1}{2}, \quad x = -4$$
</details>
