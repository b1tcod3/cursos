# Ejercicio 1: Variación directa con el cuadrado de $x$

La cantidad $y$ varía directamente con el cuadrado de $x$. Si $y = 24$ cuando $x = 3$, encuentra $y$ cuando $x = 4$.

<details>
<summary>Ver respuesta</summary>

La fórmula es $y = kx^2$. Hallamos la constante:

$$k = \frac{y}{x^2} = \frac{24}{3^2} = \frac{24}{9} = \frac{8}{3}$$

La ecuación es:

$$y = \frac{8}{3}x^2$$

Evaluamos en $x = 4$:

$$y = \frac{8}{3}(4)^2 = \frac{8}{3} \cdot 16 = \frac{128}{3}$$
