# Ejemplo 1: Resolver un problema de variación directa

La cantidad $y$ varía directamente con el cubo de $x$. Si $y = 25$ cuando $x = 2$, encuentra $y$ cuando $x = 6$.

## Solución

La fórmula general para variación directa con un cubo es $y = kx^3$. Hallamos la constante dividiendo $y$ entre el cubo de $x$:

$$k = \frac{y}{x^3} = \frac{25}{2^3} = \frac{25}{8}$$

Usamos la constante para escribir la ecuación:

$$y = \frac{25}{8}x^3$$

Sustituimos $x = 6$ y despejamos $y$:

$$y = \frac{25}{8}(6)^3 = \frac{25}{8} \cdot 216 = 675$$

## Análisis

La gráfica de esta ecuación es una cúbica simple que pasa por el origen. No todas las variaciones directas se ven así: pueden ser lineales, cuadráticas, cúbicas, etc., pero **todas pasan por $(0,0)$**.
