# Ejemplo 3: Resolver un problema de variación inversa

Una cantidad $y$ varía inversamente con el cubo de $x$. Si $y = 25$ cuando $x = 2$, encuentra $y$ cuando $x = 6$.

## Solución

La fórmula general para variación inversa con un cubo es:

$$y = \frac{k}{x^3}$$

Hallamos la constante **multiplicando** $y$ por el cubo de $x$:

$$k = x^3 y = 2^3 \cdot 25 = 200$$

Escribimos la ecuación:

$$y = \frac{200}{x^3}$$

Sustituimos $x = 6$ y despejamos $y$:

$$y = \frac{200}{6^3} = \frac{200}{216} = \frac{25}{27}$$

## Análisis

La gráfica de esta ecuación es una función racional: conforme $x$ crece, $y$ decrece.
