# Ejercicio 1: Función racional a partir de transformaciones

Dada la función recíproca cuadrada desplazada **3 unidades a la derecha** y **4 unidades hacia abajo**, escribe esto como una función racional. Luego, encuentra los interceptos $x$ y $y$ y las asíntotas horizontales y verticales.

<details>
<summary>Ver respuesta</summary>

La función recíproca cuadrada es $g(x) = \frac{1}{x^2}$. Desplazada 3 a la derecha y 4 abajo:

$$f(x) = \frac{1}{(x - 3)^2} - 4$$

Como una sola fracción:

$$f(x) = \frac{1 - 4(x - 3)^2}{(x - 3)^2} = \frac{-4x^2 + 24x - 35}{(x - 3)^2}$$

**Intercepto $y$:**

$$f(0) = \frac{-35}{9} \approx -3.89 \quad \to \quad (0, -35/9)$$

**Interceptos $x$:** numerador = 0:

$$-4x^2 + 24x - 35 = 0 \implies 4x^2 - 24x + 35 = 0$$
$$x = \frac{24 \pm \sqrt{576 - 560}}{8} = \frac{24 \pm 4}{8} \implies x = \frac{7}{2} \text{ o } x = \frac{5}{2}$$

Interceptos $x$: $\left(\frac{7}{2}, 0\right)$ y $\left(\frac{5}{2}, 0\right)$.

**Asíntota vertical:** $x = 3$ (denominador cero).

**Asíntota horizontal:** grados iguales (2 y 2), coeficiente principal del numerador $-4$ y del denominador $1$:

$$y = -4$$
