# Ejemplo 1: Asíntotas verticales y horizontales

Encuentra las asíntotas verticales y horizontales de:

$$f(x) = \frac{(2x - 1)(2x + 1)}{(x - 2)(x + 3)}$$

## Solución

### Asíntotas verticales

El denominador es cero cuando:

$$x - 2 = 0 \implies x = 2$$
$$x + 3 = 0 \implies x = -3$$

### Asíntota horizontal

Expandimos numerador y denominador:

$$(2x - 1)(2x + 1) = 4x^2 - 1 \qquad (x - 2)(x + 3) = x^2 + x - 6$$

Ambos tienen grado 2, así que la asíntota horizontal es el cociente de los coeficientes principales:

$$y = \frac{4}{1} = 4$$

### Respuesta

- Asíntotas verticales: $x = 2$ y $x = -3$.
- Asíntota horizontal: $y = 4$.
