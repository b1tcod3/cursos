# Ejemplo 2: Interceptos de una función racional

Encuentra los interceptos de:

$$f(x) = \frac{(x - 2)(x + 3)}{(x - 1)(x + 2)(x - 5)}$$

## Solución

### Intercepto $y$

Evaluamos la función en cero:

$$f(0) = \frac{(0 - 2)(0 + 3)}{(0 - 1)(0 + 2)(0 - 5)} = \frac{(-2)(3)}{(-1)(2)(-5)} = \frac{-6}{10} = -\frac{3}{5} = -0.6$$

El intercepto $y$ es **$(0, -0.6)$**.

### Interceptos $x$

Ocurren cuando la función es cero, es decir, cuando el **numerador** es cero:

$$0 = (x - 2)(x + 3)$$
$$x = 2 \quad \text{o} \quad x = -3$$

Los interceptos $x$ son **$(2, 0)$** y **$(-3, 0)$**.
