# Ejercicio 3: Factorización por agrupación

Factoriza:

a. $2x^2 + 9x + 9$

b. $6x^2 + x - 1$

<details>
<summary>Ver respuesta</summary>

**a.** $2x^2 + 9x + 9$: con $ac = 18$ y suma $9$, los números son $3$ y $6$.

$$2x^2 + 3x + 6x + 9 = x(2x + 3) + 3(2x + 3) = (2x + 3)(x + 3)$$

**b.** $6x^2 + x - 1$: con $ac = -6$ y suma $1$, los números son $3$ y $-2$.

$$6x^2 + 3x - 2x - 1 = 3x(2x + 1) - 1(2x + 1) = (2x + 1)(3x - 1)$$
