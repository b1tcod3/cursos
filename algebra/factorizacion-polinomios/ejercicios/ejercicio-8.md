# Ejercicio 8: Exponentes fraccionarios o negativos

Factoriza:

$$2(5a - 1)^{\frac{3}{4}} + 7a(5a - 1)^{-\frac{1}{4}}$$

<details>
<summary>Ver respuesta</summary>

El menor exponente es $-\frac{1}{4}$, así que el GCF es $(5a - 1)^{-\frac{1}{4}}$:

$$(5a - 1)^{-\frac{1}{4}}\left(2(5a - 1) + 7a\right) = (5a - 1)^{-\frac{1}{4}}(10a - 2 + 7a) = (5a - 1)^{-\frac{1}{4}}(17a - 2)$$
</details>
