# Ejemplo 3: Factorizar un trinomio por agrupación

Factoriza por agrupación:

$$5x^2 + 7x - 6$$

## Solución

Tenemos un trinomio de la forma $ax^2 + bx + c$ con $a = 5$, $b = 7$ y $c = -6$.

### Paso 1: Calcular $ac$

$$ac = (5)(-6) = -30$$

### Paso 2: Listar los factores de $ac$ y buscar la suma $b$

| Factores de $-30$ | Suma de factores |
|-------------------|------------------|
| $1, -30$          | $-29$            |
| $-1, 30$          | $29$             |
| $2, -15$          | $-13$            |
| $-2, 15$          | $13$             |
| $3, -10$          | $-7$             |
| $-3, 10$          | $7$ ✔            |

Así, $p = -3$ y $q = 10$.

### Paso 3: Reescribir la expresión original como $ax^2 + px + qx + c$

$$5x^2 - 3x + 10x - 6$$

### Paso 4: Sacar el GCF de cada parte

$$x(5x - 3) + 2(5x - 3)$$

### Paso 5: Sacar el GCF de toda la expresión

$$(5x - 3)(x + 2)$$

### Verificación

Multiplicamos con FOIL:

$$(5x - 3)(x + 2) = 5x^2 + 10x - 3x - 6 = 5x^2 + 7x - 6 \quad ✔$$
