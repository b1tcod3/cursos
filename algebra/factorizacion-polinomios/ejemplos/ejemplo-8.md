# Ejemplo 8: Exponentes fraccionarios o negativos

Factoriza:

$$3x(x + 2)^{-\frac{1}{3}} + 4(x + 2)^{\frac{2}{3}}$$

## Solución

### Paso 1: Sacar el término con el menor exponente

Los exponentes involucrados son $-\frac{1}{3}$ y $\frac{2}{3}$. El menor es $-\frac{1}{3}$, así que el GCF es:

$$(x + 2)^{-\frac{1}{3}}$$

### Paso 2: Sacar el GCF

$$(x + 2)^{-\frac{1}{3}}\left(3x + 4(x + 2)\right)$$

### Paso 3: Simplificar

$$(x + 2)^{-\frac{1}{3}}(3x + 4x + 8) = (x + 2)^{-\frac{1}{3}}(7x + 8)$$

### Verificación

Multiplicamos:

$$(x + 2)^{-\frac{1}{3}}(7x + 8) = 7x(x + 2)^{-\frac{1}{3}} + 8(x + 2)^{-\frac{1}{3}}$$

Reescribiendo $7x = 3x + 4x$ y $4x = 4(x + 2) - 8$:

$$3x(x + 2)^{-\frac{1}{3}} + 4(x + 2)(x + 2)^{-\frac{1}{3}} = 3x(x + 2)^{-\frac{1}{3}} + 4(x + 2)^{\frac{2}{3}} \quad ✔$$
