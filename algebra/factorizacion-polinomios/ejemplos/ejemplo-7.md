# Ejemplo 7: Diferencia de cubos

Factoriza:

$$8x^3 - 125$$

## Solución

### Paso 1: Confirmar que el primer y el último término son cubos

$$8x^3 = (2x)^3 \qquad \text{y} \qquad 125 = 5^3$$

### Paso 2: Escribir la forma factorizada como $(a - b)(a^2 + ab + b^2)$

Con $a = 2x$ y $b = 5$:

$$(2x - 5)(4x^2 + 10x + 25)$$

### Verificación

Multiplicamos:

$$(2x - 5)(4x^2 + 10x + 25) = 8x^3 + 20x^2 + 50x - 20x^2 - 50x - 125 = 8x^3 - 125 \quad ✔$$

> **Nota:** el trinomio $4x^2 + 10x + 25$ no puede factorizarse más.
