# Ejemplo 1: Factorizar el GCF

Factoriza el mayor factor común (GCF) de la expresión:

$$6x^3y^3 + 45x^2y^2 + 21xy$$

## Solución

### Paso 1: GCF de los coeficientes

El GCF de $6$, $45$ y $21$ es:

$$3$$

### Paso 2: GCF de las variables

- El GCF de $x^3$, $x^2$ y $x$ es $x$ (la menor potencia).
- El GCF de $y^3$, $y^2$ y $y$ es $y$ (la menor potencia).

### Paso 3: Combinar para hallar el GCF de la expresión

$$3xy$$

### Paso 4: Determinar el factor multiplicador de cada término

Buscamos qué multiplica al GCF para obtener cada término del polinomio:

$$3xy(2x^2y^2) = 6x^3y^3$$
$$3xy(15xy) = 45x^2y^2$$
$$3xy(7) = 21xy$$

### Paso 5: Escribir la expresión factorizada

$$(3xy)(2x^2y^2 + 15xy + 7)$$

### Verificación

Multiplicamos usando la propiedad distributiva:

$$(3xy)(2x^2y^2 + 15xy + 7) = 6x^3y^3 + 45x^2y^2 + 21xy \quad ✔$$
