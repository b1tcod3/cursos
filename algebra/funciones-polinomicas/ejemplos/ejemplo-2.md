# Ejemplo 2: Función polinómica a partir de composición de funciones

Un oleoducto revienta en el Golfo de México, causando una mancha de petróleo de forma aproximadamente circular. La mancha tiene actualmente 24 millas de radio, pero este radio aumenta 8 millas cada semana. Escribe una fórmula para el área cubierta por la mancha.

## Solución

### Paso 1: Escribir la relación lineal del radio

El radio $r$ de la mancha depende del número de semanas $w$ transcurridas:

$$r(w) = 24 + 8w$$

### Paso 2: Escribir el área del círculo

$$A(r) = \pi r^2$$

### Paso 3: Componer las funciones

$$A(w) = A(r(w)) = A(24 + 8w) = \pi(24 + 8w)^2$$

### Paso 4: Multiplicar para obtener la forma general

$$A(w) = \pi(24 + 8w)^2 = \pi(576 + 384w + 64w^2) = 576\pi + 384\pi w + 64\pi w^2$$

Esta fórmula es un ejemplo de **función polinómica**: es la suma de un número finito de términos no nulos, cada uno con una variable elevada a una potencia entera no negativa.
